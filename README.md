# optimize-jeepney-routes-NSGA2

## Prerequisites
* Python free-threading
* GDAL
* uv package manager

## Setup
Run if u wanna update the venv:
```
uv sync
```
Run if u wanna add a package:
```
uv add <package>
```

Run if u wanna update the amenity map submodule:
```
git submodule update --remote
```
